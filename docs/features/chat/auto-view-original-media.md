# 自动查看原图/原视频

> 打开聊天里的图片 / 视频时自动点击「查看原图 / 查看原视频」，直接看原画质

## 类别

聊天

## 类型

可开关

## 描述

在聊天中打开图片或视频时, 自动点击「查看原图 / 查看原视频」按钮, 直接显示原始画质的媒体内容, 无需手动操作。

视频的原始文件可能较大 (例如 64MB), 若使用流量请留意。

## 使用方法

在模块设置中启用

## 实现说明

微信图片 / 视频查看页 (`com.tencent.mm.ui.chatting.gallery.ImageGalleryUI`) 的
「查看原图 / 查看原视频」按钮, 类型与出现时机都不固定 (可能是自定义 View,
文案带体积后缀, 且异步填充)。因此实现不按字段类型枚举按钮, 而是:

- 从该页 `onCreate` / `onResume` 起一个轻量轮询, 在视图树里找「可见且文案命中关键字」
  的 TextView 并点击它 (或最近的可点击祖先);
- 已定位的两个 dex 方法 (`setImageHdImgBtnVisibility` / `checkNeedShowOriginVideoBtn`)
  仍然 hook, 作为「按钮状态刚更新」的续期信号;
- 轮询在命中 / 页面销毁 / 超时 / 关闭功能时自行停止;
- 命中与启动状态均会打印日志 (tag `AutoViewOriginalMedia`)。
